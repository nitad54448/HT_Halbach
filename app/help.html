1. Workflow & access modes

The workstation measures transverse electrical response in a rotating Halbach field and derives Hall transport quantities from calibrated voltage, current, angle and sample geometry. Temperature can be off, monitored, or controlled. Results remain accessible without the instruments.

  1. Method: select DC field, AC field or CHIRP and its excitation/acquisition principle.
  2. Devices: select compatible instruments, enter addresses and calibration, then run CHECK connections.
  3. Sample: enter identity, conducting thickness, tilt and any independently measured sheet resistance.
  4. Experiment setup: set electrical conditions and build the temperature/acquisition sequence.
  5. Run: start, monitor, pause/resume or abort.
  6. Data inspect: examine raw samples, fit overlays, current slopes and exclusions.
  7. Analysis: review physical properties, edit per-run analysis inputs and export results.
Access modeAvailable operations
Local workstationA browser at an allowed loopback URL connects automatically to the Rust service on the same PC. Hardware checks, real acquisition and explicit simulation become available.
Analysis modeGitHub Pages, remote web origins, directly opened files and PCs without a connected local service provide saved-project inspection, analysis, masks, exports and reports. Project settings cannot unlock acquisition.

Dark mode is the switch at the top right. The preference is stored in the browser, independently of project data, and shared with Help on the same origin. Light mode is the initial default. Printing uses a light background.

2. Installation & startup

On the measurement PC, double-click start-workstation.bat. It builds changed Rust sources when needed, starts the local service and opens the interface after the service responds. The default address is http://127.0.0.1:8765. A local session is established automatically; there is no token to copy.

powershell -File rust-backend/start.ps1 -ServeUi -OpenBrowser

# Rebuild without starting the service
powershell -File rust-backend/start.ps1 -BuildOnly

# Additional local development origin
powershell -File rust-backend/start.ps1 -AllowOrigin http://127.0.0.1:5502

The launcher uses a release executable when up to date, otherwise Cargo builds the current sources. A workspace-local Rust toolchain is supported. Stop a previous service before replacing its executable on Windows. If the service restarts, use Reconnect local service and repeat connection checks.

The Rust service binds to loopback. Host/origin checks and an automatic session credential protect hardware commands. Allowed local Live Server origins include ports 5500 and 5501. Adding a hosted origin with --allow-origin does not give that page hardware access. Session credentials are excluded from presets and projects.

4. Devices & connections

The local service address and Reconnect local service are in the top banner. Hover over or focus the ? button for startup help. Expand Devices and connections to configure instruments; collapse it to leave live readings visible. The same readings also appear on Run, immediately below the run controls.

Keithley 6220: the default address is GPIB0::6::INSTR. Loading a project or preset replaces an empty 6220 address or the previous default alias 6220 with this resource. Other custom addresses and recorded acquisition snapshots are preserved.

GPIB response termination: the backend detects the opened VISA interface, including aliases. GPIB reads use EOI (end of message) and writes assert END; serial instruments retain line termination. If an identity appears in a timeout's partial reply, data arrived but the transfer did not finish. The service rejects timed-out readings. See NI's termination guidance.

OWIS drivers: this backend sends serial commands through NI-VISA and does not load ps10.dll. No copy of that DLL is needed in this repository. Install the controller/serial drivers and NI-VISA on the measurement PC. The active service is built from rust-backend/Cargo.toml; the root tauri_rust_backend_engine.rs file is an unused reference implementation.

Select a method before choosing instruments. The Temperature control, Magnet, Current source and Measure section buttons are navigation controls. They remain usable while a verified configuration is read-only. After a successful check, use Stop setup and edit configuration before a run, or Pause during a run, to edit locked device values.

Magnet and position settings

Enter the OWIS port, baud rate, unit, axis and termination, calibrated counts per revolution and velocity conversion, +B angle and Field-angle convention. The +B angle is the stage angle where the field points along the positive reference direction; use 0° when your stage zero already corresponds to +B. The opposite field is 180° away. The convention determines whether increasing stage angle increases or decreases field angle. Changing it keeps the same +B reference. The count presets are starting values, not a calibration. The calibrated field magnitude is the field at the sample. The optical reader additionally needs chassis host, module/channel and pulses per revolution before quadrature decoding.

If the preferred optical reader is absent, unconfigured or fails its connection check, the app verifies the OWIS absolute position and reports the fallback. A motor identity alone does not establish valid position. Optical failure during acquisition aborts rather than silently changing the angular origin.

Current and detection settings

In delta mode, the PC communicates with the current source; the 2182/2182A receives setup commands through the source's RS-232 port. The service inserts a conservative 200 ms gap between serial setup commands and delta settings. It waits 500 ms after arming, then checks the armed status every 200 ms for up to 10 seconds before starting measurements. These are application timing defaults to verify with your instruments. This communication pacing is separate from the 100 ms current-polarity settling delay inside delta measurements. Abort cleanup proceeds without the setup delays.

Configure voltage compliance and the software current limit. AC amplitudes in the interface are RMS; hardware commands use the source's required convention. Independent DC voltage acquisition needs its own address. Delta requires the source-to-voltmeter serial and trigger connections; the identity check verifies the serial link, not trigger timing. An MFLI may share its device ID between AC source and Lock-in 1.

CHECK connections checks selected identities and position without starting motion or enabling outputs. Missing drivers, wrong models and unavailable devices are reported individually. Simulation checks are explicitly synthetic. Wait for TTL Ref In lock checks the selected reference without starting the motor; provide a real reference signal first.

5. Sample, angle & geometry

Enter sample ID, conducting thickness in nm, tilt ψ in degrees, notes and optional sheet resistance in Ω. Width and longitudinal probe spacing are metadata; the app does not infer sheet resistance from the transverse contact offset. Field magnitude B is entered on Devices → Magnet and must be finite and positive.

The sign convention follows the included CHIRP guide. The ideal field rotates in the laboratory XY plane; sample tilt ψ is about the transverse Y direction. Its sample-normal, longitudinal and transverse projections are:

At zero tilt, ordinary Hall sensitivity is maximal and the baseline planar sine term vanishes. Near 90°, ordinary Hall cannot be extracted by dividing by a vanishing cosine. Validate wiring polarity, electrical phase and field zero with a reference specimen of known Hall sign. In this convention a positive A₁ at zero tilt corresponds to a negative Hall coefficient.

In terms of the displayed reference, θ = s(α − α+B), where α is stage angle and α+B is the +B angle. Existing projects retain their calibration through θ₀ = −sα+B. Idle readings and acquisition use this same conversion.

Use current position as +B uses a valid motor readback to record the reference; it does not move the magnet. Align the magnet physically with +B first. The operation is disabled while configuration is locked or acquisition is active.

Instrument identity mismatch: the service refuses a device whose *IDN? model differs from the selection. The message includes role, address, expected model and the exact response. An empty reply means there was no usable identification text. Verify the alias/resource and query *IDN? in NI MAX; check termination and serial settings if needed. Select the actual model rather than bypassing identification. In delta mode, the voltmeter response comes through the current source's RS-232 link.

7. Temperature programs

Devices offers OFF, Read only and Read and control. OFF saves no measured temperature. Read only records the sensor without changing its setpoint. Control enables temperature ramps, stabilization and heater operations.

Stabilized steps and repeat counts

Select Stabilized steps in the segment builder. Enter start/end temperature, positive increment, ramp rate, heater range, measurements at each temperature and wait between measurements. Cooling is automatic when end < start. Only whole increments are generated, up to 1000 temperatures. Expand Stability criteria for temperature holds to set the window and tolerances.

Each temperature adds a stabilization operation followed by a measurement operation. Edit individual rows for different repeat counts or conditions. A measure operation supports 1–10000 acquisitions, with 0–86400 s wait between them. Every acquisition is a separate run; the wait is additional time after an acquisition.

Stability tests

Stability requires the controller ramp to have finished, continuous time within the instantaneous error band, sufficient minimum stable time and a fully covered averaging window. Mean absolute error and temperature standard deviation must also pass. An out-of-band reading resets the window.

Slow scans during temperature evolution

Select Slow scan. The builder stabilizes the starting temperature and then repeatedly acquires while heating or cooling toward the end temperature. Edit target, rate, heater range, wait, endpoint tolerance and timeout in the scan row. Scanning needs angular scan, AC-field or CHIRP acquisition. The endpoint is checked between complete acquisitions, so a final trace can extend beyond target crossing. Scan timeout is at most seven days.

With zero wait, supported single-current methods keep rotation and excitation on across saved windows. Other methods retain the required changes of current, direction and background acquisition. Each window still preserves its own raw data and settings.

Temperature associated with an acquisition

The run stores the mean, minimum, maximum, start, end, span and averaging method in temperatureStats. Inspection and results CSV show the temperature range. A fitted property during a scan represents a temperature interval; nonlinear material evolution means it need not equal the property evaluated at the mean temperature.

The minimum supported ramp defaults to 0.1 K/min. A verified Model 335 firmware 1.4 or newer may be configured for 0.001 K/min in Devices. Model 332 remains at least 0.1 K/min. The software maximum temperature and ramp limit also apply.

Other operations are Soak / wait and Heater off. A program can contain up to 10000 operations. Without temperature control, use measurement and wait operations.

8. Running & live changes

Start is enabled after valid connection checks, sample/method conditions and a valid program. Real Start can enable current and move the referenced stage. Run displays live readings, temperature history, progress and the accepted sequence. Simulation is explicitly labeled and never claims that physical equipment is online.

EditWhen it takes effect
Current, carrier, rotation, time constant and other numerical acquisition conditionsAfter Apply conditions & program, at the next complete acquisition boundary. The current trace retains its original settings.
Active scan target, rate, heater range, wait or measurement countAt the next acquisition boundary. Lowering a repeat count does not remove completed runs.
Active stabilization target / criteriaAt the next temperature check after applying; changed criteria reset the stability window.
Future sequenceAdd, remove, reorder or replace future operations, then apply. Completed operations and the active operation type remain fixed.
Instrument configuration or measurement principlePause first, edit, repeat connection checks, then resume.
Sample geometry during a programAcquisition sample metadata are fixed. Use per-run analysis corrections afterward if a recorded geometry needs correction.

Pause in a real program disables excitation and motion, releases hardware sessions and retains partial raw data. Partial traces are marked incomplete and are not fitted. Resume rechecks configuration, restores temperature stability when required, and restarts an interrupted acquisition while preserving completed repeat counts.

Abort requests cleanup and retains data already acquired. Real completion, faults and abort perform output/motion cleanup and temperature-control shutdown. The service also monitors browser polling; loss of heartbeat for more than 15 s aborts acquisition. Keep the original workstation tab open. Cleanup errors are reported in the run status and log.

Use the live readings to distinguish current, output status, voltage, field angle and temperature. Poll readings is a readback operation after connection checks; it does not start measurement. Numerical edits remain pending until applied, and earlier run snapshots are not rewritten.

9. Raw data & masking

Select a run or follow the latest saved run. Inspection shows the usable count, coefficients, statistical diagnostics, temperature range, fit errors and warnings. Angular records show X/I versus field angle with masked points and a fit overlay, X/Y versus time and angular residuals. Zero-current samples remain in raw data but are not divided by current in the angular display.

Real AC-field lock-in detection records demodulated amplitudes, not an angular waveform. Its angular fit panels are hidden, and a signed voltage-versus-current plot displays the slope/intercept instead.

Enter a finite start and end time in seconds, with end greater than start, and choose Exclude range or Restore range. The validity mask changes, the fit is recalculated, and the action is recorded in History. Restoration can include settling samples if you explicitly restore those times; inspect whether such data should be used. Masks preserve sample timestamps and the original numerical readings.

The raw table previews at most 300 samples. Export raw CSV writes all samples, including excluded ones, with time, angle, X, Y, current, temperature and validity. A rank-deficient, fully masked or incomplete run retains its raw data and an error instead of presenting derived properties.

X is the signed in-phase voltage. Y is the electrical quadrature diagnostic, not the D₁ sine harmonic of X versus field angle. The saved I is the commanded signed DC current or RMS AC amplitude; it is not an independent current-monitor measurement.

10. Fit models & equations

Angular model used by the app

CoefficientInterpretation under the baseline geometry
A₁Ordinary-Hall cosine harmonic used to derive the Hall coefficient.
D₁First sine harmonic; a diagnostic for phase/angle mismatch and additional first-harmonic response.
A₂Second sine harmonic, a candidate planar transverse term when geometry/material assumptions are validated.
B₂cSecond cosine harmonic, including possible longitudinal magnetoresistance leakage.
b₀Current-proportional constant transverse offset. It is not the longitudinal sheet resistance.
o₀Current-independent output intercept. With one current level, b₀ and o₀ cannot be separately identified.

Multiple current levels allow six identifiable coefficients. At a single current, the app removes b₀ and fits a combined constant intercept, so five coefficients remain. More usable samples than coefficients are required. Poor angular coverage or redundant columns can still make a fit singular. The displayed Condition is a scaled-QR diagonal ratio used as a diagnostic, not a singular-value condition number.

Current sweep with an intercept

For angular AC-field/DC-current simulation data, fit harmonics at each current first, then regress each voltage coefficient against signed current. This separates a current-independent angular pickup from the current-proportional response.

Real AC-field demodulated amplitudes

Fit normalized voltage versus current with a free intercept when multiple levels exist. A single AC current uses V/I and assumes zero intercept; a warning indicates that independent pickup has not been subtracted. A₂ and D₁ are unavailable from this demodulated amplitude fit.

The app uses an ideal, unfiltered plateau basis after masking. It does not currently implement the forward-filtered design, drift columns, higher harmonics, field-map replacement or correlated-noise estimators discussed in the extended guide. Those equations are experimental guidance, not additional automatic corrections.

11. Physical properties

Use SI internally: conducting thickness d in m, field magnitude B in T, ψ in radians, I in A and fitted A₁/A₂ in Ω. e is the positive elementary charge, exactly 1.602176634 × 10⁻¹⁹ C.

For ordinary zero-field Hall mobility, use an independently obtained zero-field sheet resistance at the same temperature. Rotating a Halbach field into the sample plane does not create zero magnetic field. The transverse constant b₀ does not measure R□.

Planar normalization

A second sine harmonic is not by itself proof of planar Hall physics: longitudinal leakage, field mapping and angle error can contribute. C becomes unstable near zero ordinary Hall slope. The implementation only extracts ordinary quantities for |cos ψ| > 0.05 and planar quantities for |sin ψ| > 0.05. Invalid inputs and undefined/overflowing quantities are left unavailable.

Positive RH is labeled hole-like and negative RH electron-like in this convention. A Hall slope within 3σ of zero gives a weak-signal warning and no carrier assignment. At zero slope, density and carrier type are undefined.

12. Uncertainty & limitations

Statistical fit errors

The displayed fit RMS is √(RSS/(N−p)), in volts, for the angular fit. Current-sweep diagnostics combine within-current harmonic-fit residuals. Lock-in amplitude diagnostics summarize the within-level voltage noise. Unavailable uncertainties remain blank rather than being presented as measured zero.

For a current-slope fit, the implementation propagates the within-level voltage-coefficient variances, including the two-current case. With more than two currents it also estimates scatter around the fitted line and uses the larger variance estimate. A single reading at one current cannot establish its noise uncertainty.

What statistical errors do not include

Field/thickness/tilt uncertainty, contact geometry, current/voltage gain calibration, temporal correlation, sample heating and model mismatch are not included in the displayed 1σ fit errors. Lock-in filtering correlates samples; a high sample count is not the same as that many independent observations. Compare independent repeats and controlled changes of current, direction, speed and carrier frequency.

Filter and angular dynamics

Filter lag and an angle error mix cosine and sine coefficients. The current app masks transients but does not automatically correct the filter transfer function or timestamp latency. Validate these effects on the bench and inspect residual structure; the extended guide develops the forward-filtered treatment.

14. Projects, exports & reports

Open project accepts .hallproj.json / JSON. Dragging a project onto the app also works. Imported projects are validated before replacing the open project, connection state is cleared and complete runs are recalculated from raw data. Saved fit caches are not trusted. Incomplete runs remain raw-only.

ArtifactContents
Project JSONFormat/version, sample, current hardware/method settings, program, raw run arrays, per-run snapshots, analysis results/corrections, exclusions, history and captured log.
Method/device presetMethod and device configuration only. It excludes sample data, acquired runs and session credentials.
Raw CSVAll selected-run samples: t_s, theta_rad, X_V, Y_V, I_A, T_K, valid. Null temperatures remain empty.
Results CSVThe selected measured/simulated filter, fit status, temperature mean/range, physical quantities, uncertainties and warnings. Full numerical precision is exported, rather than the rounded screen values.
ReportSample, method, program, results, statistical uncertainties, per-run analysis inputs, plots, assumptions, warnings and history. Choose Print report and save as PDF if needed.

Per-run record

samples holds parallel arrays t, theta, X, Y, I, T, valid and, where recorded, direction. sample, method and hardware preserve acquisition settings. programStep, measurement, temperatureMode, continuousAcquisition and temperatureStats describe thermal acquisition. detectionKind distinguishes angular data from real field-lockin amplitudes.

Analysis corrections to thickness, field, tilt and independent sheet resistance are stored in analysisSample; they do not overwrite the acquisition sample snapshot. Restore acquisition inputs removes those corrections. Save the project to retain corrections and masks.

History records configuration, program, acquisition and analysis edits. Log has None, Normal, Verbose and Debug capture levels; the display filter is separate from capture. Debug includes instrument commands and responses. A captured log can be saved as text.

The real service autosaves completed and partial projects under rust-backend/data/. Browser-side masks and analysis corrections should also be saved using Save project. Creating a new project clears the current in-memory session after confirmation.
