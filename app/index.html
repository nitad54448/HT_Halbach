Temperature program

Build a temperature program from a start, end and positive step size (cooling sweeps are supported). Each point ramps, waits for stability, then measures using the selected measurement mode. ?T means measured temperature minus target: every reading must stay within the instantaneous limit for the entire window, and the time-averaged |?T| must meet the mean limit. A timeout or abort switches the heater off. An end point is included only when reached by a whole step.

History

Audit trail of configuration changes, program runs and data edits. Saved with the project.

Log

None: nothing recorded. Normal: connections, steps, warnings, errors. Verbose: adds step parameters and settings changes. Debug: adds every instrument command and reply, and data payloads. Warnings and errors are kept at all levels except None.

Project & report

Project file

A project holds sample, method, program, all runs (raw samples), history and the log. Load it later for analysis.

Export & report

The report includes sample, method, temperature program, results table, plots, assumptions and a summary of the log. Use “Save as PDF” in the print dialog.
