Temperature & acquisition program

Temperature control is OFF. The experiment will execute at ambient room temperature without temperature ramps or stabilization delays.

Build a temperature program from start, steps, and end temperatures (including multi-segment ramps and cooling). Temperature stability requires remaining continuously in-band for the minimum stabilization time, with time-averaged |ΔT| below the tolerance threshold and temperature standard deviation (ESD σ_T) below the ESD limit during the averaging window.

History

Audit trail of configuration changes, program runs and data edits. Saved with the project.

Log

None: nothing recorded. Normal: connections, steps, warnings, errors. Verbose: adds step parameters and settings changes. Debug: adds every instrument command and reply, and data payloads. Warnings and errors are kept at all levels except None.

Project & report

Project file

A project holds sample, method, program, all runs (raw samples), history and the log. Load it later for analysis.
