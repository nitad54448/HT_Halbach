# HT Halbach

Hall effect measurement workstation with a native Rust instrument service and interactive HTML5 frontend. Hardware access runs locally in Rust with direct instrument communication (NI-VISA, LabOne, TCP sockets, RS-232); no Python runtime or LabVIEW installation is required.

## Quick Start (One-Click)

Double-click `start-workstation.bat` in the repository root (or run it from a terminal). This script:
1. Starts the native Rust service on `http://127.0.0.1:8765`.
2. Serves the web interface from `app/`.
3. Displays your **Pairing Token** in the console.

---

## How to Get the Pairing Token

The pairing token is a 64-character security key generated by the Rust backend to ensure only your authorized browser session can send instrument commands.

You can find the token in three ways:

### Method 1: Console / Terminal Output (Recommended)
When you start the Rust service (via `start-workstation.bat` or `rust-backend/start.ps1`), look at the terminal output:

```text
========================================================
      Starting Halbach Hall Workstation Service
========================================================

Rust hardware service: http://127.0.0.1:8765
Pairing token: 8a4f91c3d0b27e45a90184c2f1e56789...
Open the UI in Live Server or GitHub Pages. No instruments are accessed until requested.
```

- Highlight the text after `Pairing token: `, right-click or press <kbd>Enter</kbd> to copy it.

### Method 2: From the Saved Token File
The backend automatically persists the token to disk so it stays consistent between restarts:
- File path: `rust-backend/data/service.token`
- Open this file with Notepad or run in PowerShell:
  ```powershell
  Get-Content rust-backend/data/service.token
  ```
- Copy the entire token string.

### Method 3: Custom Token via CLI
You can also launch the service with your own chosen token (must be at least 16 characters):
```powershell
powershell -File rust-backend/start.ps1 -Token "MySecretLabToken1234"
```

## Where to Paste the Token in the UI

1. Open the UI at `http://127.0.0.1:8765` (or `http://127.0.0.1:5500/app/` if using VS Code Live Server).
2. Go to **Tab 2: Devices** (`Devices and connections`).
3. Under the **Local Rust service** card:
   - **Service URL**: `http://127.0.0.1:8765`
   - **Pairing token**: Paste your copied token here.
4. The token is saved in your browser session and used to authenticate all hardware checks and measurement commands.
5. Configure your instruments and click **CHECK connections**.

For hardware requirements, OWIS settings, Zurich MFLI setup, and runtime details, see [Rust setup and supported hardware](rust-backend/README.md) and [UI workflow](app/README.md).
